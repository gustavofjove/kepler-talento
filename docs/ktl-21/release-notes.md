# KTL-21 release notes

- Candidates can be assigned catalog-managed tags and filtered by tag with `ANY` or `ALL`
  semantics.
- Candidate detail includes a separate custom-note thread with individual editing, concurrency,
  authorship, and logical retirement.
- System or historical notes without an internal author id display `Autor desconocido`.
- `No contactar` is a descriptive tag only; this release does not enforce a contact prohibition.
