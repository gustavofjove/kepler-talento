Changes in advanced search

- Buttons on preset bar to be smaller (same size as rest of buttons on same page)
- Remove "Cargar" (load) button
- The "Historial de exportaciones" panel at the bottom will be a modal that will open up when clicking a new "Historial de exportaciones" button at the top (besides "Exportar CSV")
- "Habilidad", " Idiomas" and "Programas" will become drop down menus joined to their paired "Nivel de xxx" (level of xxx) so you can add a new filter to a read-only summary list of filters (where you can also delete them) for each type ("Habilidad", " Idiomas" and "Programas") that will be displayed below the specific type once added. You can e.g. add as many lines to "idiomas" with different levels as you want and the list will allow you to select if "Cualquiera" (Any, OR) or Todos (All, AND) for that specific type. The different types will always run an "all" or "AND" query.
- Search params panel collapsable. It's collapsed by default when results are displayed and expanded when no results are returned. When collapsed it will display a summary of the filters entered in a reduced summary view.

The containers for the filter types ("Habilidad", " Idiomas" and "Programas") will not have titles, as they're already visible just below (dropdown menu label).

On the other hand, the "Texto" textbox will have a standard size and will be placed on the RHS of the "Texto" label. Below, keeping the left 50% width column, the CV filter will be placed (kept as a drop down menu). On the RHS (50% width column) we will have the "Estados" filter that will become a multi-checkbox group instead of the selection list.
