# KTL-25 release notes

Search levels now mean the selected level or any higher level in the applicable catalog
family's configured order. This applies to skills, languages, and programs. An empty level
continues to match any level.

Saved search presets and position requirements keep their stored filters unchanged. Those
with a selected level may now return more candidates, including candidates whose level is
higher than the selected minimum. Catalog administrators should review the order of the
three level families, since reordering them changes the search ranking immediately.
